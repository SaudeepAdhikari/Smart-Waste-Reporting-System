# Database

This folder contains all database-related resources for the Smart Waste Management System.

## Technology Stack

- **Database**: PostgreSQL
- **Spatial Extension**: PostGIS

## Structure

- **migrations**: Database schema migrations
- **seeds**: Seed data for development and testing
- **functions**: Custom database functions and stored procedures
- **views**: Database views for complex queries
- **indexes**: Custom database indexes
- **scripts**: Utility scripts for database operations
- **backups**: Database backup files

## Notes

- All database resources are kept separate from application code
- PostGIS will be used for geospatial operations
- Migrations will be managed through a migration tool (to be decided)
