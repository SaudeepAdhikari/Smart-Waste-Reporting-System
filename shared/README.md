# Shared

This folder contains shared types, constants, validation schemas, and utilities used across the Smart Waste Management System.

## Structure

- **types**: TypeScript type definitions shared across applications
- **constants**: Application-wide constants
- **validation**: Validation schemas and rules
- **schemas**: Data schemas and interfaces
- **utils**: Shared utility functions

## Purpose

To avoid code duplication and ensure consistency across:
- Client application
- Municipality application
- Collector application
- Backend server

## Usage

Import shared resources from this folder to maintain consistency across the system.
